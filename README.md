## 📈 Git Workflow & Standards

1. Feature Branching: Every feature or page section is built in its dedicated branch to maintain main stability.
2. Conventional Commits: Meaningful commit messages follow standard syntax (feat:, fix:, docs:, refactor:).
3. Clean Code Structure: Emphasis on clean file organization, readable code, and reusable UI components.
